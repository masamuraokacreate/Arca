# Arca - Blueprint.md (Arcaとは何か)

## コンセプト
「どの機能を使っているか」よりも、「その情報が自分の生活の中でどうつながっているか」を大切にするシステムです。
単なる便利なモジュールの寄せ集めではなく、使っているうちに自分の生活全体が一つにつながっていく感覚を提供します。

## Aether Coreの役割
Arcaの中核であり、情報を静かにつなぐシステムです。
- **自我を持たない:** 「おはよう」といった人間らしい振る舞いや人格は持ちません。
- **控えめな提案:** レシピから買い物リストを推測するなど、情報のつながりを見つけて提案しますが、ユーザーの許可なく勝手にデータを書き換えることはありません。

## 扱う情報の領域
- **行動・予定 (Tasks / Calendar / Habits)**
- **記録・知識 (Memory / Notes / Knowledge)**
- **生活 (Shopping / Travel / Recipes / Finance)**
- **趣味 (Photos / Music / Games / Ideas)**

起動時のホーム画面では、「今日の情報 → 各モジュール」の順で展開し、「今日自分に必要な情報」が一目でわかるようにします。
