# Arca - Roles.md (開発の役割分担)

Arcaの開発における、あなたと各ツールの役割分担を定義します。

- **司令塔・設計者 (あなた):**
  - Arcaの全体設計、デザインの意思決定、「どんな機能が欲しいか」を指示する役割。
- **Google Antigravity IDE (作業机):**
  - メインの開発環境。AIエージェントにプロンプトを投げてUIや基本ロジックを生成させる場所。
- **Google Jules (裏方のアシスタント):**
  - バックグラウンドで動く非同期エージェント。テストコードの作成やコードの整形などを担当。
- **Firebase (データハブ):**
  - PCとiPhoneのデータ同期、PWAとしてのアプリ配信を担当。
- **Gemini API (Aether Core / AIの脳):**
  - アプリ内部で動く中枢。情報の構造化や関連付けなどを自動で処理する役割。
