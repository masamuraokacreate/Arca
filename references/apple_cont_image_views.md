# 画像ビュー (Image views) - Apple Human Interface Guidelines

> 出典: [Apple Developer Documentation - 画像ビュー (Image views)](https://developer.apple.com/jp/design/human-interface-guidelines/image-views/)

画像ビュー（Image View）には、透明または不透明な背景の上に1つの画像が表示されます。場合によっては、画像のアニメーションシーケンスが表示されることもあります。

---

## ベストプラクティス (Best practices)

* **単に画像を表示することを主な目的とする場合に使用する。**
  画像ビューは、写真、イラスト、アイコンなどのビジュアルコンテンツを表示するために最適化されています。
* **インタラクティブな画像にはボタンを使用する。**
  画像がタップ可能で何らかのアクションをトリガーする場合は、画像ビューにジェスチャーを追加するのではなく、システム標準の「ボタン（Button）」コンポーネントを使用し、その中に画像を設定してください。これにより、アクセシビリティやフォーカス状態（tvOSやMac）が正しく処理されます。
* **適切なコンテンツモード（Content Mode / Scaling）を選択する。**
  画像の縦横比（アスペクト比）を維持しながら表示領域に合わせる設定を適切に行います:
  * **Aspect Fit (拡大・縮小して収める):** アスペクト比を維持し、画像全体がビュー内に収まるようにします（余白ができる場合があります）。
  * **Aspect Fill (拡大して全体を覆う):** アスペクト比を維持しながらビュー全体を埋めます（はみ出た部分は切り取られます/クリップ）。
  * **Scale to Fill (歪めて引き伸ばす):** 通常は避けるべきです（画像が縦長や横長に歪むため）。
* **高解像度ディスプレイ（Retina / Super Retina）向けのアセットを提供する。**
  `@2x` および `@3x` の解像度のアセットを用意し、あらゆるデバイスで鮮明に表示されるようにします。
* **アクセシビリティの代替テキスト（Accessibility Label）を提供する。**
  画像ビューが重要な情報を伝えている場合は、VoiceOverが読み上げられるように簡潔で明確な代替テキストを設定します。単なる装飾目的の画像はアクセシビリティ要素から除外（非表示）します。

## プラットフォーム別の考慮事項 (Platform considerations)

### iOS / iPadOS / macOS / visionOS
追加の特別な考慮事項はありません。標準のレイアウトやマテリアルと調和させてください。

### tvOS
tvOSで画像にフォーカスが当たるようにする場合は、画像ビュー単体ではなくフォーカス可能なコンポーネントと組み合わせ、視差効果（Parallax）や拡大効果が自然に適用されるようにします。

### watchOS
画面サイズとメモリに制限があるため、画像アセットのファイルサイズと解像度を最適化し、アニメーション画像を表示する際はパフォーマンスへの影響に注意します。
